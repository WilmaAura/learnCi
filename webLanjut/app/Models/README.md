# Fungsi Model

- Model digunakan untuk penghubung antara aplikasi dan database. Model bertanggung jawab untuk mengelola proses pengambilan, penyimpanan, pembaruan, hingga penghapusan data.
- **Seluruh logika database** dipusatkan pada satu tempat, sehingga **Controller** tidak perlu menangani query secara langsung.
